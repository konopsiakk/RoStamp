# RoStamp

**Update icons for Roblox, in seconds.**

RoStamp turns your game icon into an update icon: an hourglass with "UPDATE!", a title strip, or a corner ribbon. It runs in your browser at [konopsiakk.online/RoStamp](https://konopsiakk.online/RoStamp/) or as a Windows app. No sign-in, and your image never leaves your device.

## Features

- **Three types:** Update (hourglass + text), Title strip (straight or wavy, top/middle/bottom, tilt) and Corner ribbon.
- **5 hourglass styles:** Classic, Pixel, Curved, Glow and Blocky, with your own frame and sand colours.
- **9 fonts:** Arial Black, Fredoka, Luckiest Guy, Bangers, Baloo 2, Russo One, Press Start 2P, Anton and Permanent Marker, with outline, shadow and an optional pill behind the text.
- **Image tools:** drag to move, scroll or pinch to zoom, black filter, blur and colour tint.
- **Small-size preview** at 150, 64 and 40 px, so you can check readability.
- **Countdown pack:** one icon per label (12 HOURS, 6 HOURS, … UPDATE!) in a single .zip, ready for [RoIcon](https://konopsiakk.online/RoIcon/) timers.
- **Quick looks and your own presets**, plus PNG export at 512 or 1024 and copy to clipboard.

## Run from source

```
npm install
npm start          # desktop app
npm run dist:win   # build the Windows installer
```

The web version is just `src/`: open `src/index.html` or host the folder.
